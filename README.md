# Topragh (توپراق)

**Topragh** یک فرهنگ لغت آزادِ ترکمنی ↔ فارسی و انگلیسی است. این پروژه یک
وب‌سایت سریع و کاملاً استاتیک برای جست‌وجو، مرور و بهبود واژه‌های ترکمنی فراهم
می‌کند.

وب‌سایت: [topragh.ir](https://topragh.ir)

## چه چیزهایی در پروژه هست؟

- جست‌وجوی سریع میان مدخل‌های ترکمنی، فارسی و انگلیسی
- مرور واژه‌ها بر اساس حرف آغازین و صفحهٔ مستقل برای هر مدخل
- اجرای جست‌وجو در مرورگر با MiniSearch، بدون نیاز به سرور جست‌وجو
- دادهٔ استانداردشده در `data/canonical/` و ابزارهای ساخت شاخص جست‌وجو
- مسیر روشن برای گزارش خطا و پیشنهاد اصلاح واژه‌ها از طریق Issue و Pull Request

## فناوری‌ها

- Astro، Vue و TypeScript
- MiniSearch برای شاخص و جست‌وجوی سمت کاربر
- خروجی استاتیک، مناسب میزبانی روی هر سرویس سازگار با فایل‌های استاتیک

## اجرای محلی

پیش‌نیاز: Node.js 22.12 یا جدیدتر.

```bash
git clone https://github.com/kakajan/topragh.git
cd topragh/web
npm install --legacy-peer-deps
npm run dev
```

دادهٔ جست‌وجو هنگام build به‌صورت خودکار تولید می‌شود. برای بررسی و ساخت نسخهٔ
نهایی:

```bash
npm run check
npm run build
```
